# Email Template Builder

Визуальный конструктор Email-рассылок. Собираешь письмо из блоков в редакторе, видишь живой предпросмотр и экспортируешь готовый табличный HTML, совместимый с почтовыми клиентами.

🔗 **[Посмотреть живое демо](https://EHOTCKuu.github.io/email-template-builder/)**

Проект сделан как пет-проект, чтобы на практике показать работу со сложными структурами данных, генерацией HTML, динамическими формами и инженерной культурой: строгая типизация, линтеры, тесты, доступность.

## Стек

- **Vite** + **React 18** + **TypeScript** (strict)
- **Redux Toolkit** — состояние шаблона и синхронизация с `localStorage`
- **React Hook Form** — динамические формы инспектора с `reset` при смене блока
- **SCSS Modules** — стилизация, классы в camelCase, дизайн-токены в переменных
- **Jest + React Testing Library** — юнит- и интеграционные тесты
- **ESLint + Stylelint** — проверка кода и стилей
- Архитектура — упрощённый **Feature-Sliced Design**: `app`, `entities`, `features`, `widgets`, `shared`

## Как это работает

### Рабочая область

Три колонки: слева слои и блоки, в центре холст предпросмотра, справа инспектор настроек.

Слои можно добавлять (шесть типов блоков: шапка, hero-баннер, текст, CTA-кнопка, карточка товара, подвал), перемещать вверх/вниз, дублировать и удалять. Кнопки перемещения автоматически дизейблятся на краях списка.

### Компилятор письма

Отдельная чистая функция `compileEmailToHtml(state)` собирает валидную табличную вёрстку: `role="presentation"` на всех таблицах, инлайн-стили, `bgcolor` для клиентов, игнорирующих CSS, MSO-conditional стили для Outlook и скрытый прехедер.

Экранирование применяется в одном месте — в хелперах `attribute()` и `escapeHtml()`, поэтому контент блока не может «протечь» через разметку. Компилятор детерминирован: одинаковый вход даёт побайтово одинаковый выход, это зафиксировано тестом.

Вёрстка адаптивная: медиа-запрос по ширине письма складывает колонки карточки товара друг под друга на мобильных, а контентная таблица сжимается по ширине окна.

### Предпросмотр

Письмо рендерится внутри изолированного `<iframe srcDoc sandbox="">`. Стили редактора не могут сломать вёрстку письма, а письмо не может выполнить JS. Переключатель ширины Desktop (600px) / Mobile (375px) на кнопках с `aria-pressed`. Выбранный в списке слой подсвечивается пунктирной рамкой прямо на холсте.

### Линтер письма

Перед экспортом письмо проверяется на типовые ошибки рассылок:

- `alt` у всех изображений;
- непустые `href` и предупреждение, если ссылка без схемы `http(s)`;
- размер итогового HTML против лимита Gmail в 102 КБ (считается в байтах, кириллица в UTF-8 занимает два байта).

Проблемы показываются списком, клик по проблеме выделяет соответствующий блок в редакторе.

### Экспорт и сохранение

- Модальное окно с готовым кодом на вкладках HTML/JSON, кнопкой «Скопировать» (с тостом об успехе) и «Скачать файл».
- Экспорт и импорт шаблона в `.json`. При импорте структура проверяется рантайм-валидацией (`isEmailTemplateState`), поэтому битый или подменённый файл не попадёт в стор.
- Автосохранение черновика в `localStorage` с debounce. При чтении данные тоже валидируются — старая версия схемы или обрезанная запись просто игнорируются.
- Кнопка «Сбросить до шаблона по умолчанию».

## Доступность

- Полная навигация с клавиатуры, включая переключение блоков и работу в списке слоёв.
- Модальное окно: ловушка фокуса, закрытие по Escape, возврат фокуса на элемент, с которого окно открыли.
- Связь `label` и `input` во всех формах инспектора через `useId`.
- `aria-pressed` у переключателей, `aria-label` у иконочных кнопок, `role="dialog"` и `aria-modal` у модалки.
- Контрастность текста не ниже WCAG AA.

## Тесты и качество кода

- **Тесты:** `npm test` (Jest + RTL). 61 тест в 8 файлах: компилятор HTML, экранирование, редюсеры `emailSlice`, `localStorage`, линтер письма, формы инспектора, модалка экспорта.
- **Типы:** `npm run typecheck` — `tsc --noEmit` в strict-режиме.
- **Линтеры:** `npm run lint` (ESLint, flat config) и `npm run lint:styles` (Stylelint).
- **Сборка:** `npm run build` — `tsc --noEmit && vite build`.
- **CI/CD:** GitHub Actions прогоняет линтеры, типы и тесты перед деплоем на GitHub Pages. Если что-то падает — сайт не обновляется.

## Структура

- **src/app** — композиция приложения, store, провайдеры, типизированные хуки
- **src/entities/email** — домен письма: типы блоков, компилятор HTML, линтер, фабрика блоков, работа с `localStorage`
- **src/features** — фичи: управление блоками, инспектор, линтер-отчёт, экспорт, автосохранение
- **src/widgets** — панели и холст: `layers-panel`, `canvas-preview`, `inspector-panel`
- **src/shared** — UI-кит, хуки, стили, конфиг
- **public/images** — локальные SVG-плейсхолдеры для дефолтного шаблона

## Запуск

```bash
git clone https://github.com/EHOTCKuu/email-template-builder.git
cd email-template-builder
npm install
npm run dev
```

Открыть `http://localhost:5173`.

Требуется Node 22.18+ (в `package.json` прописано поле `engines`).

## Команды

```bash
npm run dev           # запуск в режиме разработки
npm run build         # типы + production-сборка
npm run preview       # предпросмотр собранной версии
npm run typecheck     # проверка типов
npm test              # тесты
npm run test:coverage # тесты с покрытием
npm run lint          # ESLint
npm run lint:styles   # Stylelint
```
